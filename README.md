# my-little-corner-of-space
A 3D website showcasing some of my Blender models I created in a space-themed environment.

### Controls:
Move: WASD  
Rise/Descend: R/F  
Rotate: Q/E  
Look Around: mouse movement

### Built with:
[node.js](https://nodejs.org/en)  
[vite](https://v3.vitejs.dev)  
[three.js](https://threejs.org)  

### Why I built this project:
I wanted to experiment with three.js and showcase some of my basic Blender 3D models.
